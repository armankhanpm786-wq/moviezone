# moviezone
CinemaZone is a modern movie content website built with HTML, JavaScript and Firebase. Users can post movie titles and descriptions which are saved in real-time database. It is fast, responsive and beginner friendly. This project helps learn web development, CMS system, and Firebase integration easily for creating online earning platforms.
# 🎬 MovieZone Project

MovieZone is a simple movie CMS website built with HTML, JavaScript and Firebase.

## Features
- Add movie posts
- Real-time database (Firebase)
- View all movies instantly
- Mobile friendly design

## Tech Used
- HTML
- CSS
- JavaScript
- Firebase Realtime Database

## Purpose
This project is for learning web development, CMS system and Firebase integration.
